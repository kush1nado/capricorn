Capricorn

Команда агентов на одном экране.

Киберпанк-терминал в красно-чёрной палитре. Архитектор, менеджер, 2–3 кодера, ревьюер и тестировщик работают рядом с git-панелью и общей лентой.

Агенты передают друг другу ход через @упоминания, спорят и критикуют. Ты можешь вмешаться в любой момент из строки ввода.

Каждому агенту — своя модель. Claude, OpenAI, DeepSeek, Qwen, MiniMax, OpenRouter, Ollama, LM Studio.

Команда агентов

@architect

Архитектор. С ним можно отдельно обсудить архитектуру. Может читать файлы и проверять чужую работу в worktree.

@manager

Менеджер распределяет работу и ставит задачи кодерам. После APPROVED вливает ветку агента. При споре спрашивает тебя с вариантами A/B.

@coder1

Кодер. Читает и изменяет файлы, запускает тесты. Работает в собственной ветке и отдельном git worktree.

@coder2

Кодер. Читает и изменяет файлы, запускает тесты. Параллельные правки в отдельных worktrees не мешают друг другу.

@coder3

Третий кодер подключается через --complex или /complex on. Как и другие кодеры, может изменять файлы и запускать тесты.

@reviewer

Ревьюер сверяет код с требованиями. Может смотреть чужие файлы и diff, запускать тесты в worktree агента.

@tester

Тестировщик может создавать и изменять файлы, запускать тесты. Работает в собственной ветке и отдельном worktree.

Главные возможности

Три режима

Один интерфейс в терминале (capricorn), браузере (--web) и собственном окне (--desktop). Веб-сервер слушает только 127.0.0.1.

Отдельные worktrees

У каждого кодера и тестировщика своя ветка capricorn/<агент>. Ревьюер проверяет работу до слияния, менеджер вливает её после APPROVED.

Codex CLI и Claude Code CLI

Агенты могут работать через установленный CLI под подпиской ChatGPT или Claude, в пределах её лимитов. У каждого агента своя сессия CLI и свои инструменты.

Сессии по проектам

Лента, история, очереди, токены, бюджет и модели автоматически сохраняются после каждого хода. capricorn --resume продолжает сессию, /export сохраняет переписку в Markdown.

Установить и запустить

Windows, Linux и macOS. Для установки из исходников нужен Python ≥ 3.10. В корне проекта создай окружение.

python -m venv .venv
Установка через Python и запуск по ОС
ОСУстановкаЗапуск
Windows.venv\Scripts\python -m pip install -e .Двойной клик по Capricorn.cmd или .venv\Scripts\capricorn
Linux, macOS.venv/bin/python -m pip install -e ..venv/bin/capricorn или source .venv/bin/activate, затем capricorn

Для собственного окна установи дополнение pip install -e ".[desktop]". На Linux нужен GTK (sudo apt install python3-gi gir1.2-webkit2-4.1) или Qt.

Готовое приложение

Скачай архив для своей ОС на странице Releases, распакуй и запусти.

  • Windows — Capricorn-Windows.zip
  • macOS — Capricorn-macOS.tar.gz
  • Linux — Capricorn-Linux.tar.gz

На стартовом экране выбери проект, модели агентов и новую или последнюю сессию. Нажми Enter для запуска.

В стандартном Terminal.app на macOS тема использует 256-цветную палитру. В iTerm2, Ghostty, WezTerm и Kitty доступна полная палитра.
